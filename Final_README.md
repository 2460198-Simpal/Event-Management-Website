# EventHub - Responsive Event Management Website

An event management web application developed for the **K Explore Web Designing** task.

## Features Implemented
- **Hero & Countdown Banner**: Features an interactive event countdown clock.
- **Dynamic Event Catalog**: Displays event cards with titles, dates, venues, categories, and image covers.
- **Real-Time Filtering**: Live search bar and category dropdown.
- **Interactive Modal & Form**: Modal popup pre-populated with selected event details.
- **JavaScript Form Validation**: Client-side validation for Name, Email format, and 10-digit Phone numbers.
- **Bonus Challenges Included**:
  - Dark/Light Theme toggle using CSS variables.
  - LocalStorage data retention for user registrations.
  - Animated card loading and smooth modal transitions.

## Tech Stack
- HTML5
- CSS3 (Flexbox, CSS Grid, Media Queries, Keyframes)
- JavaScript (ES6+, DOM Manipulation, LocalStorage API)

## Local Execution
1. Open `index.html` in any web browser.
